# 桥梁结构实验室 · 交接文档

面向：下一个接手这个模块的人（也可能是三个月后的你自己）。
读完之后你应该能：① 看懂每个数字从哪来；② 安全地改参数和加功能；③ 不踩已经踩过的坑。

---

## 0. 一句话说清它是什么

**一个跑在浏览器里的平面梁单元有限元求解器**，外面包了一层桥梁专业的外壳：
车道荷载、冲击系数、横向分布系数、影响线最不利布载、JTG 规范验算。
零依赖（不用 numpy / 不用后端），全部是原生 JS，所以能直接 iframe 进星屿。

入口：星屿侧边栏「桥梁结构实验室」→ `bridgelab/index.html`
也可单独打开：`http://127.0.0.1:8620/bridgelab/index.html`
深链指定桥型：`?p=0` ~ `?p=4` 对应左侧五个预设

| `?p=` | 桥型 | 分跨 (m) | 截面 | 混凝土 |
|---|---|---|---|---|
| 0 | 20m 简支 T 梁 | 20 | T 梁 | C50 |
| 1 | 30m 简支 T 梁（**无参数时的默认**） | 30 | T 梁 | C50 |
| 2 | 40m 简支箱梁 | 40 | 单箱单室 | C50 |
| 3 | 3×30m 连续箱梁 | 30,30,30 | 单箱单室 | C50 |
| 4 | 45+70+45 连续箱梁 | 45,70,45 | 单箱单室 | C55 |

## 1. 为什么不用现成的专业软件

| 路线 | 代表 | 为什么没选 |
|---|---|---|
| 商业桥梁设计软件 | 桥梁博士 V4、midas Civil、CSiBridge、LUSAS Bridge | 年费 3.5–8 万元，闭源，Windows 原生 EXE，**塞不进星屿**；而且它给结果不给解释，入门者看完还是不懂 |
| 开源通用有限元 | OpenSees / OpenSeesPy、CalculiX、Kratos | 能算且免费，但要装 Python 环境 + 学 Tcl/Python 建模，**结果也不给解释**；且本机 scipy/matplotlib 缺失、沙箱装不上包 |
| **自研教学内核**（本项目） | — | 零依赖、秒开、可嵌入；**每一步都能展开成公式**；代价是只算平面弯曲 |

定位不是「替代专业软件」，是**「看得懂的透明计算器」**：帮你在正式设计之前建立直觉。
README 底部和页面横幅都写明了这个边界，不要改成"专业设计软件"的说法。

## 2. 文件结构与职责

```
bridgelab/
├── fem.js         有限元内核（纯数学，不含任何桥梁知识）
├── bridge.js      桥梁专业知识（材料、截面、荷载、规范公式）
├── app.js         参数绑定 / 求解调度 / 图形渲染 / 计算书生成
├── style.css      样式（Apple 深色语言）
├── index.html     页面骨架
├── test-fem.js    内核对照验算（node 直接跑）
├── README.md      本文件
└── _test.html     浏览器版验算台（可选）
```

**分层原则：`fem.js` 不许出现"车道""冲击系数"这类词，`bridge.js` 不许出现矩阵运算。**
想加新桥型只动 `bridge.js` 和 `app.js`；想把单元从欧拉梁换成铁木辛柯梁只动 `fem.js`。

## 3. 核心数据流

```
readParams()          读左侧面板 → 参数对象 P
  ↓
F.buildMesh(spans)    分跨 → 节点坐标 xs / 支座索引 supIdx
F.makeSolver(...)     组装总刚 → 只做一次 LU 分解（关键性能点）
  ↓
F.distribute()        把荷载分配到单元（整体坐标 → 局部坐标）
F.assembleF()         等效结点荷载向量
solver.solveF()       LU 回代 → 位移 d
F.elemResults()       端内力 + 内部采样点
  ↓
ilScan()              影响线扫描（几何不变时缓存）
  ↓
包络计算              均布铺同号区 + 集中放峰值
  ↓
check()               规范验算
  ↓
renderElev / renderChart / renderReport
```

### `fem.js` 的约定（改之前必须读）

- 坐标 x 沿桥纵向，单位 m
- 每节点 2 个自由度：`[v, θ]`，v 向上为正，θ 逆时针为正
- **荷载向下为正**，输入时内部会取负号（见 `elemEquiv`）
- **弯矩 M 以「下缘受拉」为正**（跨中正弯矩为正）
- 内力反算公式：`V_i = f[0]`、`M_i = −f[1]`、`V_j = −f[2]`、`M_j = +f[3]`

### 性能关键点

`makeSolver` 把总刚**只分解一次**，之后任意荷载向量只需回代。
影响线扫描（30 节点 → 30 次求解）因此从秒级降到毫秒级。
**不要**图省事在循环里重新 `assembleK`，那会让"拖滑块"直接卡死。

## 5. 已踩过的坑（重要，别踩第二遍）

### 5.1 剪力控制截面：活载符号不能当恒载的增量

早期版本找最大剪力截面时，把活载当成恒载的同号增量：

```js
// ❌ 错：右支座处活载是负的，这样算出来是 −258 kN（真值 −1123 kN）
Vd = γG·V_G + γQ·max(envVmax − V_G, −(envVmin − V_G))
```

正确做法是**正负两种活载布置分别组合**，再比绝对值：

```js
// ✅ 对
vd1 = γG·V_G + γQ·(envVmax − V_G);
vd2 = γG·V_G + γQ·(envVmin − V_G);
```

### 5.2 控制截面必须用「组合后设计值」找

不能拿标准值包络的最大值当控制截面。恒载 γG=1.2、活载 γQ=1.4，权重不同，
一个包络值略小但活载占比高的截面，组合后反而更大。
**枚举所有截面，逐个算 γ₀Md / γ₀Vd，取最不利。**

### 5.3 浮点噪声会让「并列最大值」随机选边

简支梁两端的 |V| 完全相等（手算 884/884），浮点误差使 `>` 判断任意挑一个。
先修 5.1 之后副作用消失了，但这个陷阱还在——**任何"取最大值"的地方都要考虑并列情形**。

### 5.4 绘图符号约定必须和内力符号约定一致

弯矩以「下缘受拉」为正 → 正弯矩画在**下方**。
`renderChart` 里偏移量写成 `mid + (isM ? 1 : -1) * v * sc`，
早期写成 `-1`，结果简支梁弯矩图整个上下颠倒。

### 5.5 `min(Vcs, Vmax)` 才是真正的抗剪抗力

`Vmax` 是截面尺寸上限（斜压破坏），一旦超过，**加密箍筋完全无效**，
必须加大腹板宽或梁高。所以抗力取两者较小值，并且分开报告，
否则用户会以为"再多配点箍筋就行"。

### 5.6 无头浏览器渲染不出内容时，先看控制台

`--dump-dom` 出来只有原始 HTML（`pillMesh` 还是 `—`）说明 JS 抛异常了。
加 `--enable-logging=stderr` 才能看到 `Uncaught ReferenceError`。
另外同一个 `--user-data-dir` 被上次进程占着会导致加载失败，换一个目录即可。

### 5.7 `sampleNodal` 的位移必须从解向量取

`v[]` 不能留空。挠度验算直接读它，留空会静默算出 0 mm 的假"通过"。

### 5.8 预设按钮的高亮必须显式设置（2026-09-16 修）

`PRESETS` 里的按钮是 JS 循环创建的，但 `applyPreset()` 原先**从来不设置高亮 class**。
后果：无论你点哪个预设、或用 `?p=N` 深链，左侧按钮的蓝色高亮**一直停在错的那个上**，
看起来像"深链没生效"，其实参数是对的、只有高亮在骗人。

修法：`applyPreset(p, idx)` 增加第二个参数，末尾统一 toggle `.on`；
按钮创建时写 `data-pidx`，`b.onclick = function () { applyPreset(p, i); }`；
深链处 `applyPreset(PRESETS[pIdx], pIdx)`。
`style.css` 补上缺失的 `.preset button.on`（用 `var(--blue)`，**注意本文件没有 `--accent` 变量**）。

**教训**：验证深链时不要靠"截图字节数是否变化"判断，因为高亮变化也会改变字节数。
要抓 DOM 核对 `.preset button.on` 落在第几个；或者一次性截 5 个预设，
确认产出 **5 张互不相同**的图（`unique images: 5 / 5`）。

## 7. 已知边界（没做 / 不能做）

- **只算平面弯曲**：不含横向分布的空间效应、剪力滞、扭转、畸变
- **不建模实际的横隔梁与桥面板**：横向分布靠一个系数 m 代表
- **不含施工阶段**：一次落架，没有悬臂拼装/顶推/体系转换
- **不含收缩徐变、预应力损失**：As 只是"受拉钢筋面积"，不是预应力束
- **基频用简支梁公式估算**：连续梁会偏保守，UI 已标注
- **横向分布用偏心压力法**：宽跨比 > 0.5 时会自动提示"宜用 G-M 法"
- **只做承载能力极限状态 + 挠度**：不含裂缝宽度、疲劳、抗震
- **Pₖ 内插用最大跨**：连续梁严格应按各跨分别计算

**结论：可以做教学演示和学习工具，不能用于施工图设计。**

## 8. 常见改动怎么做

### 加一个桥型预设
`app.js` 顶部 `PRESETS` 数组加一项即可，字段含义看现有项。同时可深链 `?p=N`。

### 加一种截面形式
1. `bridge.js` → `makeRects()` 加分支，返回矩形条带列表
2. `index.html` → `pSecKind` 加按钮
3. `bridge.js` → `check()` 里 `bf` / `hf` 的取值逻辑补上新形式

### 换成更精确的单元（铁木辛柯梁）
只改 `fem.js` 的 `elemK` 与 `elemEquiv`，加上剪切修正系数。
也可以直接引 PyNite 的思路，但注意别引入构建流程。

### 加"我这样改会怎样"的 A/B 对比
`compute(P)` 是纯函数，同一个 P 可以调两次。
最省事的做法是在 `check()` 之后跑两套 P，画成对照表。
