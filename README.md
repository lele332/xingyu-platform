# ○ 零 · 个人学习工作台

> 为大学生打造的个人 AI 学习与工作平台：课程作业管理、学习笔记库、专注统计、成长档案、数据看板、AI 助手。黑白灰三色极简，本地优先。

## ✨ 功能一览

| 模块 | 说明 |
|------|------|
| 📊 **仪表盘** | 今日待办、倒计时日历、任务完成率环形图、7日专注趋势、最近笔记、🕐 右上角节日+农历时钟 |

## 🚀 快速使用

### 方式一：本地打开
直接用浏览器打开 `index.html` 即可使用（数据保存在浏览器 localStorage）。
> 提示：仅“AI 对话”和“二维码”功能需要联网（AI 需配置 API Key，二维码需加载 CDN 库），其余功能完全离线可用。

### 方式二：部署到 GitHub Pages（推荐，获得永久链接 + 扫码访问）

1. **创建仓库**：在 GitHub 新建一个仓库（如 `my-student-platform`）。
2. **上传代码**：把本目录下的 `index.html`、`css/`、`js/` 全部上传到仓库。
3. **开启 Pages**：仓库 → `Settings` → `Pages` → Source 选择 `Deploy from a branch` → 选择 `main` 分支的根目录 `/` → Save。
4. **等待发布**：1-2 分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`。
5. **扫码访问**：打开平台右上角「⌘」按钮，粘贴你的部署链接，即可生成二维码，手机扫码永久访问。

## 📰 热点新闻（每日更新）

在侧边栏「热点新闻」查看每日国内外热点：

- **国内**：央视网、中新网
- **国际**：联合早报（新加坡主流媒体，中文报道国际+中国新闻）

### 手动更新
```bash
cd ai-student-platform
python scripts/fetch_news.py
```
会重新抓取并生成 `data/news-data.json`，刷新页面即可看到最新新闻。

### 每日自动更新
已通过 WorkBuddy 定时任务配置（每天早上 7:30 自动抓取）。如需修改时间，在 WorkBuddy 的「定时任务」中调整"星屿平台·每日热点新闻抓取"。

> 说明：因网络环境限制，BBC/CNN 等国外英文媒体在国内无法直接抓取，故国际新闻选用联合早报（新加坡）——它本身就是国外媒体的中文报道，覆盖国际热点更全面、可稳定获取。

## 🤖 配置 AI 模型

AI 助手支持任意 **OpenAI 兼容接口**，在右上角「⚙ 设置」中配置：

| 预设 | Base URL | 模型 | 说明 |
|------|----------|------|------|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` | 国内直连，性价比高（推荐） |
| Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` | 长文本能力强 |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` | 需科学上网 |

> 🔒 密钥仅保存在**你的浏览器本地**（localStorage），不会上传到任何服务器，可放心使用。
> 未配置 AI 时，四大技能会自动降级为**本地规则引擎**（DDL+优先级打分排序、模板化规划等），功能依然可用。

## 🔐 API Key 安全须知（重要！）

你的 DeepSeek API Key 已写入 **`js/local-config.js`**（本地配置文件，平台会自动读取）。

> ⚠️ **部署到 GitHub 前必须注意**：
> 1. 已内置 `.gitignore` 会忽略 `js/local-config.js`，正常情况下不会被 git 提交
> 2. 如果手动拖拽上传文件到 GitHub 网页，**务必不要上传 `js/local-config.js`**，否则密钥公开泄露！
> 3. 若误传导致泄露，请立即到 [DeepSeek 开放平台](https://platform.deepseek.com) 重置密钥
> 4. 已配置的 Key 仅在你本地浏览器生效，其他人访问部署站点时不会看到（但请仍按上述规则保护源码文件）

## 📥 一键导入课表

在「课程作业」页面点击 **📥 导入课表**，支持两种方式：

| 方式 | 说明 |
|------|------|
| 📷 **上传截图** | 上传课表截图，AI 视觉识别课程名称/时间/地点（需要配置支持视觉的模型，如 `gpt-4o-mini`、`glm-4v`） |
| 📋 **粘贴文本** | 从教务系统/课表 App 复制文字粘贴，AI 自动解析；未配置 AI 时本地规则也能解析常见格式（如 `周一 8:00-9:40 高等数学 教学楼A-301`） |

识别结果会先预览确认，再一键导入全部课程（自动跳过重名课程）。

## 📥 一键导入成绩

在「成长档案」的成绩卡点击 **📥 导入成绩**：

| 方式 | 说明 |
|------|------|
| 📋 **粘贴文本** | 从教务系统/成绩单复制文字，AI 或本地规则自动解析科目/考试名/分数/学分/学期（支持 `高等数学 期中考试 88分 5学分`、`科目:高等数学 成绩:91 学分:4`、`2026春 高等数学 期中 88 5学分` 等格式） |
| 📷 **上传截图** | 成绩单截图 AI 视觉识别（需配置支持视觉的模型） |

导入后自动计入 GPA 统计，重复成绩自动跳过。

## 📥 一键导入笔记

在「学习笔记库」页面点击 **📥 导入笔记**：

## ☁ 云同步（桌面 / 手机共用一份数据）

平台默认本地存储；如需在桌面和手机之间同步，在「设置 → 云同步」开启：

1. 在 GitHub 生成一个 Personal Access Token（Settings → Developer settings → Personal access tokens → Tokens (classic)），勾选 gist 权限即可（Gist 接口仅支持 classic token）。
2. 把 Token 粘贴到「云同步」输入框，勾选「启用云同步」，点「立即同步」。
3. 平台会自动创建一个私有 Gist 存放你的数据，之后另一端（手机/桌面）填入同一个 Token 并开启同步即可自动互相同步。

> 说明：
> - 数据只在你的浏览器与私有 Gist 之间流动，无第三方服务器；Token 仅保存在本机浏览器。
> - 改动后约 2 秒自动同步；打开平台时也会自动拉取最新。
> - 冲突时以较新一端的修改为准（个人单用户场景，简单可靠）。

## 💾 数据安全

- 所有数据存储在浏览器本地（localStorage），无需注册登录。
- 支持「设置 → 导出数据(JSON) / 导入数据」一键备份迁移。
- 注意：清除浏览器缓存会丢失数据，重要数据请定期导出。
